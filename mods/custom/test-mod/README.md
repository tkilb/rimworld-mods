## Overview

A custom RimWorld mod (xml).

## Structure

- `About/`: Metadata and version compatibility declarations (`About.xml`).

- `Textures/`: (Optional) Mod graphics and icons.
- `Sounds/`: (Optional) Mod audio clips.
- `Patches/`: (Optional) XML patch operations modifying vanilla or third-party Defs.
